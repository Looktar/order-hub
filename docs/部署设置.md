# 部署设置（只需做一次，约 10 分钟）

整套系统免费：网页放在 GitHub Pages，数据放在 Supabase 免费版。你只需要把 Supabase 的三样信息填进 GitHub，之后每次代码更新都会自动测试和部署。

## 第 1 步：在 Supabase 拿三样东西

1. **项目编号（Project ID / Reference ID）**
   打开 supabase.com，进入你的项目 → 左下角 Project Settings → General → 复制 **Project ID**（一串约 20 位的小写字母）。
2. **数据库密码**
   就是新建项目时你设的那个密码。忘了的话：Project Settings → Database → Reset database password，重设一个并记下来。
3. **访问令牌（Access Token）**
   点右上角头像 → Account preferences → Access Tokens → Generate new token，名字随便填（比如 order-hub），复制生成的令牌（以 `sbp_` 开头）。

> 这三样都**不要**发在聊天里，也不要提交进仓库，只填在下一步的 GitHub 设置里。

## 第 2 步：填进 GitHub

打开 https://github.com/Looktar/order-hub/settings/secrets/actions

**Secrets** 标签页，点 New repository secret，添加两个：

| Name | Secret |
|---|---|
| `SUPABASE_ACCESS_TOKEN` | 第 1 步的访问令牌 |
| `SUPABASE_DB_PASSWORD` | 第 1 步的数据库密码 |

再切到 **Variables** 标签页，点 New repository variable，添加一个：

| Name | Value |
|---|---|
| `SUPABASE_PROJECT_REF` | 第 1 步的项目编号 |

可选：再加一个 Secret `BACKUP_PASSPHRASE`，随便设一句长密码并自己记好。设了才会每周自动备份数据（备份用这个密码加密）。

## 第 3 步：打开网页托管，开始部署

先打开 https://github.com/Looktar/order-hub/settings/pages ，在 Build and deployment → Source 里选 **GitHub Actions**（只需选一次，不用点保存）。

然后打开 https://github.com/Looktar/order-hub/actions → 左边选"测试并部署" → 右边 Run workflow。
三个步骤都变绿就完成了（约 3 分钟）。网页地址是 **https://looktar.github.io/order-hub/**

## 第 4 步：建第一个管理员（你自己）

1. Supabase 项目里 → Authentication → Users → Add user → Create new user，填你的邮箱和密码，勾选 Auto Confirm User。
2. 打开网页 https://looktar.github.io/order-hub/ ，用这个邮箱和密码登录。
3. 页面会提示"设置第一个管理员"，填上姓名即可。你会成为公司角色的管理员。
4. 在"设置 → 账号管理"里给销售、公司同事和司机开通账号。没有邮箱的人可以用自定的登录名，比如 `wang01`。

> 管理员是公司角色，所以能看到全部订单。如果你自己要以销售身份下单，再给自己开一个销售账号（用另一个登录名）。

## 出问题时

- Actions 里哪一步变红，点进去看红色那一行的说明。最常见的是 Secret 名字拼错，或者数据库密码不对。
- Supabase 免费项目连续 7 天没人用会暂停。系统每 3 天会自动访问一次来防止暂停；万一还是暂停了，进 Supabase 项目点 Restore 即可，数据不会丢。
